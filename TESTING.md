# Stork Flight - Testing Notes

## Devices tested
- My Android phone
- Samsung phone with enlarged font settings
- Desktop browser
- Online multiplayer over VPN

## Issues discovered
- Enlarged system fonts caused oversized buttons.
- Players could change difficulty during an online match.

## Lessons learned
Testing on one device is not enough.
Different settings can reveal usability problems
that aren't visible during development.

## Future improvements
- Better support for accessibility settings
- More automated multiplayer tests
- Testing on additional screen sizes
